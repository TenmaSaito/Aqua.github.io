# ゲーム制作ポートフォリオ

GitHub Pagesで配信できる、ビルド不要の静的サイトです。外部ライブラリー・外部フォント・アクセス解析は使用していません。

## 確認する

波が上がる途中は、波を通過した文字から切り替え先の文字色になります。文字単位で波の形に追従し、独自の背景を持つカード・ボタンの文字は、その背景と一緒に満水後に補間します。文字追従に未対応のブラウザーでは、上下移動のないフェードに切り替えます。

テーマ切り替えは、切り替え先の色を薄めた水の波が下から背景だけを満たし、新しいテーマへゆっくりなじむ演出です。文字やカードは波の手前に残り、満水後に配色を補間します。切り替え中の連打は無視します。OSで「視差効果を減らす／アニメーションを減らす」を有効にすると、上下移動を省いたフェードになります。色と時間は `appearance.css` の `.theme-water`、処理は `theme-control.js` で調整できます。

`index.html` をブラウザーで開きます。Node.jsがある場合は、このフォルダーで `node preview.cjs` を実行し、表示されたURLから確認できます。

`preview.html` はCSSと掲載データを内蔵した、デザイン相談用のスナップショットです。ダブルクリックしてブラウザーで確認できます。元のファイルを変更した後は `node make-preview.cjs` で再生成してください。画像・動画を追加した場合は `assets` フォルダーも隣に置いてください。日常の編集確認には、常に最新のファイルを読み込む `index.html` を使えます。

## 掲載内容を更新する

編集するのは基本的に **content.js** だけです。プロフィール・言語の使用歴・参加出展イベントには提供された情報を反映しています。作品の個別情報・参加年・アプリ使用歴は、判明したものから追記できます。

| 項目 | 編集箇所 |
| --- | --- |
| 名前・学校・自己紹介 | profile |
| 学校名・学科・専攻（各行に表示） | profile.school・profile.course・profile.specialization |
| 卒業年・卒業予定年月 | profile.graduation（空なら非表示） |
| ブラウザータブのアイコン | site.favicon |
| 作品 | games |
| GitHubの制作プロジェクト一覧 | sourceProjects |
| 技術・アプリ・使用歴・できること | skillGroups の items |
| 参加・出展イベント | events |
| 連絡用メールアドレス | profile.email |
| GitHub等のリンクとアイコン画像 | profile.links の url・icon |
| スプラッシュの画像・文字・表示時間 | presentation.splash |
| インターン経験 | internships |

配列の既存の `{ ... }` をコピーして追加すると、表示件数も自動的に増えます。作品カテゴリの絞り込みボタンも自動で生成されます。表示順は記入順です。不要な項目は削除でき、作品やイベントは `[]` にすると準備中の表示になります。

- 文字列は `"..."` で囲み、項目の間にカンマを入れます。文章中の改行は `\n`、ダブルクォートは `\"` と書きます。
- 画像は `assets` に入れ、作品の `image` に `assets/画像名.webp` などの相対パス、`imageAlt` に画像の説明を書きます。先頭に `/` を付けないことでリポジトリ名付きのURLにも対応します。
- 作品の `links` やプロフィールの `links` に `{ label: "GitHub", url: "https://github.com/ユーザー名" }` のような項目を追加できます。リンクがない場合は `[]` にします。
- 複数のスクリーンショットは作品の `screenshots` に `{ src: "assets/scene-01.webp", caption: "ステージ画面" }` を追加します。空の場合はメイン画像が作品詳細にも表示されます。
- プレイ動画は `video: { src: "assets/play.mp4", youtubeId: "", poster: "assets/cover.webp", caption: "操作の紹介" }` で設定します。YouTubeなら `src` を空にして `youtubeId` にURLの `v=` に続く11文字のIDを記入します。動画は自動再生しません。未設定なら公開モードでは動画欄を表示しません。サンプルモードでは配置予定の枠が表示されます。
- `theme` は画像未設定時の色で、`mint`、`peach`、`lavender` を指定できます。
- 実際の情報に差し替えたら `sampleMode: false` にしてサンプル表示の案内を消します。これはサンプルデータ自体を削除する設定ではありません。
- レイアウトは `style.css`、ダーク系の配色・演出は `theme.css`、表示処理は `app.js` で変更できます。
- 波やスプラッシュの最終的な配色・アニメーションは `appearance.css` で調整します。`water.js` が波の停止・再生と画面外での停止を制御します。端末の「視差効果を減らす」設定では静止表示になります。外部の画像・動画やライブラリーは不要です。
- `light.css` は既存の共通スタイルで、最終的なテーマとレイアウトは `appearance.css` が上書きします。色を変える場合は `appearance.css` のCSS変数を編集してください。
- タブのアイコンは `site: { favicon: "assets/my-icon.png" }` のように指定します。画像を `assets` に置いて一緒にアップロードしてください。未変更時は水滴のSVGアイコンです。アイコンはブラウザーにキャッシュされるため、変更後も古い場合はファイル名を変えるか再読み込みしてください。
- `profile.email` に公開したいアドレスを入力すると、自己紹介に連絡先欄・コピー・メール起動リンクが表示されます。閲覧者からメールを収集するフォームではありません。空の場合は準備中の表示になります。
- `profile.graduation` は、例えば `"2028年3月卒業予定"` や `"2028年卒"` のように入力します。自己紹介欄の「卒業」にそのまま表示されます。空文字 `""` なら行全体を表示しません。例の年は実際の卒業年を示すものではありません。
- GitHubリンクの `icon` に `assets/github-icon.png` などを設定すると画像を埋め込めます。空なら組み込みのGitHubマークを表示します。画像の読み込み失敗時もリンクの文字は残ります。
- X・Steamも `profile.links` で設定できます。すでに空欄の項目があるので、`url` にプロフィールやストアのURLを入れるだけで、自己紹介欄とフッターの両方へ表示されます。`icon` には任意の画像を指定できます。URLが空欄の項目は表示しません。他サービスも `{ label: "サービス名", url: "https://...", icon: "assets/icon.png" }` の形で追加できます。
- `presentation.splash.image` に追加画像のパスを指定できます（PNG・WebP・GIF・SVG等）。注水アニメーションと一緒に表示します。`enabled: false` で省略、`durationMs` で注水時間を設定できます（1200～5000ミリ秒）。スキップボタンとEscキーにも対応しています。
- `presentation.reveal: false` でスクロール時のフェードインを停止できます。トップへ戻るボタンは480px以上スクロールすると表示されます。これらの動作は `experience.js` にまとまっています。
- TOPボタンはフェードイン・アウトし、非表示中はクリックやキーボード操作の対象から外れます。カード・リンク・ボタンのホバー／押下時の動きは `light.css` の末尾で調整できます。端末の「視差効果を減らす」設定では動きを省略します。

## 昼の海・夜の海とアニメーション

メニューバーのスイッチで、透き通る水色のライトテーマと、藍色のダークテーマを切り替えます。選択はブラウザー内に保存します。最終的な配色とレイアウトは **appearance.css**、切り替え動作は **theme-control.js** です。読みやすさを優先し、両テーマとスマートフォン幅で確認してください。今後の変更でも守るルールは `AGENTS.md` に記載しています。

トップの大きな水のパネルは廃止し、波の区切りを配置しています。波は停止ボタンで止められます。スプラッシュは円に水が注がれて満ちるアニメーションです。`durationMs` は注水時間（1200～5000ミリ秒）で、満水になってから短い余韻を置き、約0.6秒でフェードアウトします。本文も徐々に表示されます。画像を指定した場合も、注水アニメーションは残ります。

参考：[モーションリファレンス](https://motion-reference.takayustudio.jp/)、[ゲームUI演出の基本](https://gameanimation.info/archives/5603)。状態変化を伝える短い動きと、文字の読みやすさを優先して独自に実装しています。

## インターン経験を追加する

`internships` に次の形で追加します。空の項目は省略できます。`learnings` は複数行の箇条書きです。

```js
{
  company: "企業名", period: "参加期間",
  title: "取り組みのタイトル", description: "制作内容",
  role: "担当したこと", learnings: ["学んだこと"], links: []
}
```

## 技術欄に作品リンクを表示する

`content.js` の技術項目にある `languages: ["C", "C++"]` と、各作品の `tools` を照合し、該当する作品名を自動表示します。作品名をクリックするとその作品の詳細が開きます。絞り込み中でも表示できます。今後、`tools: ["C#", "Unity"]` の作品を追加すると、C#欄にも自動でリンクが増えます。現在掲載中の6作品はC/C++のため、C#欄には未確認の作品を表示していません。

## 作品を追加する

`games: []` の中に、次のような項目を追加します。複数ある場合は項目の間をカンマで区切ります。ここに示す文字列は書き方の例です。

```js
games: [
  {
    title: "作品名", subtitle: "ジャンルなど", category: "個人制作", year: "2026", theme: "mint",
    image: "assets/game-cover.webp", imageAlt: "ゲーム画面",
    description: "作品の概要", tools: ["C++"], role: "担当した内容",
    period: "制作期間", team: "1名", detail: "ゲームの内容・操作など",
    highlights: ["実装で工夫したところ"],
    screenshots: [{ src: "assets/game-screen.webp", caption: "プレイ画面" }],
    video: { src: "assets/play.mp4", youtubeId: "", poster: "assets/game-cover.webp", caption: "プレイ動画" },
    links: []
  }
]
```

画像・動画・リンクがまだない場合は、該当するパスを空文字、配列を `[]` にできます。最初の作品を登録すると、概要の準備中表示に代わって作品カードが表示されます。
